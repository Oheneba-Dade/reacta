# reacta Project Brief

## One-Sentence Summary

A reaction video library with semantic search on tags and transcripts.

## Problem

Finding reaction videos is hard. Users search by filename or rely on memory.
Semantic search enables finding clips by _meaning_, not exact words.

## Solution

- Upload short clips
- Tag with natural language descriptions
- Automatically transcribe speech
- Search by meaning: "bro walking weird" finds "man walks awkwardly"

## Example

Tag: "man walks awkwardly"
Search: "bro moving weird"
Result: Match (semantic similarity, different wording)

## Success Metrics (Phase 1)

- [ ] Can upload clips + tags
- [ ] Can search by tags
- [ ] Can search by spoken words (transcripts)
- [ ] Search feels instant (<200ms)
- [ ] Personal library fully searchable (~200 clips)

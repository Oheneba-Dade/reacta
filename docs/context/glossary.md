# reacta Glossary

## Core Concepts

**Clip:** A short second video file representing one moment/emotion.

**Tag:** User-written description of a clip.

- Multiple per clip
- Examples: "man walks awkwardly", "funny walk", "bro moving weird"
- Searchable as vectors

**Embedding:** Vector (list of numbers) representing semantic meaning.

- Created by sentence-transformers
- Stored in pgvector
- Used for similarity search

**Semantic Search:** Finding items by meaning, not keywords.

**Transcript:** Spoken words extracted from clip.

- Generated by Whisper (automatic)
- Split into overlapping chunks
- Each chunk searchable

## Technical Terms

**pgvector:** PostgreSQL extension for vector similarity.

**sentence-transformers:** Python library for text embeddings.

- Model: all-MiniLM-L6-v2 (384 dimensions)

**Whisper:** OpenAI's speech-to-text model.

- ~85% accuracy

**Chunk:** Segment of transcript (~256 characters).

## Phases

**Phase 1:** MVP (personal library, your clips only)
**Phase 2:** Sharing (invite friends to view)
**Phase 3:** Submissions (user-contributed clips with moderation)
**Phase 4:** Public libraries (if warranted)
